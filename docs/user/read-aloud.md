# Read agent replies aloud

Under a completed agent reply, select **Read EN** / **Read English** or
**Read DE** / **Read German**. These choose the voice language; they do not translate
the reply. Pause, resume or stop using the same controls. If your browser blocks
automatic playback, press **Play** once the audio is ready.

Speech is generated locally using installed Windows desktop voices on the
environment hosting the thread. The audio plays only on the device where you
pressed the button, including a phone connected to that environment. The Windows
PC must be on and connected; no cloud speech service or microphone is used.
Mac and Linux speech generation are not supported in this version.

The selected English or German desktop voice must be installed and enabled in
Windows. A missing language produces an error rather than using the wrong voice.
Your PC's voice quality depends on its installed voices.

Code blocks, images, tables and raw HTML are skipped. Up to 6,000 characters of
spoken text are supported per reply; longer replies show an error instead of
silently omitting the end. One reply plays at a time per device. Generated audio
is not saved on the server; the native phone client uses a temporary cache file
that is removed when playback is closed or replaced.
